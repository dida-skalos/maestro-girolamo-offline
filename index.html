💾 Proteggi il tuo lavoro

I dati sono conservati in questo browser sul dispositivo. Esporta regolarmente una copia: cancellando i dati del browser potresti perderli.

Per scaricare una copia usa il pulsante «Salva» in alto.

Prima di sostituire i dati, verrà richiesto il download di una copia di sicurezza. Controlla che il file sia stato scaricato prima di confermare.

🔄 Sincronizzazione Wi-Fi

Questa copia funziona senza server. Ogni dispositivo conserva un archivio separato; trasferisci i dati con backup manuali.

Modalità offline: nessuna connessione al Mac.

Non esiste sincronizzazione automatica: evita di modificare lo stesso archivio su due dispositivi prima di importare il backup più recente.

Attenzione: I dati locali non sono cifrati. Non utilizzare dati personali reali prima della verifica delle misure di sicurezza e delle disposizioni scolastiche.
